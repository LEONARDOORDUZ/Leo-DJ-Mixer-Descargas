# Leo DJ Mixer — Descargas

Repositorio público para bajar Leo DJ Mixer. La música de cada persona se queda en su computador o en su celular.

## Computador

Versión 0.35 para Windows:

https://github.com/LEONARDOORDUZ/Leo-DJ-Mixer-Descargas/releases/download/v0.35-computador/Leo-DJ-Mixer-Computador-V0.35.zip

Descomprima el archivo, instale Node.js y Google Chrome, y abra `CREAR-ACCESO-DIRECTO.bat`. En el escritorio queda el programa Leo DJ Mixer. La música se coloca en `D:\Musica`.

## Celular

La aplicación de Android versión 0.35:

https://github.com/LEONARDOORDUZ/Leo-DJ-Mixer-Descargas/releases/download/v0.35-laboratorio/Leo-DJ-Mixer-V0.35.apk

Instálelo sin desinstalar la versión anterior. En el celular, Buscar actualizaciones encuentra esta versión.
